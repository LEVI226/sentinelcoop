# Checklist livraison Topic 1

## Produit

- Prototype lancé en local sur Windows.
- Interface utilisable sur écran mobile ou navigateur responsive.
- Mode dégradé documenté.
- README avec installation, lancement et description des données.
- Démo live répétée.

## Fonctionnel

- Filtrage client contre sanctions/PPE.
- Matching approximatif avec explication du score.
- Gestion des homonymies.
- Filtrage transaction.
- Alertes informatives et bloquantes.
- File de revue conformité.
- Journal d'audit.
- Solde global multi-comptes.
- Cumul des opérations par client.

## Données

- Dataset synthétique versionné.
- Dictionnaire de données.
- Sources publiques citées.
- Aucune donnée personnelle réelle.
- Scénarios de test inclus.

## GRC

- Rôles utilisateur définis.
- Décision humaine conservée.
- Seuils configurables.
- Mises à jour de listes horodatées.
- Actions sensibles journalisées.
- Justification obligatoire de clôture d'alerte.
- Export des alertes.

## Pitch

- Problème expliqué en une phrase.
- Démo centrée sur trois parcours.
- Architecture simple.
- Impact mesurable.
- Contraintes SFD prises en compte.
- Briques tierces et IA déclarées.
